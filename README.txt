سيف شوبينج — Saif Shopping
============================
طريقة الرفع على السيرفر:
1. ارفع مجلد saif-shopping كاملاً إلى public_html (أو www) في الاستضافة.
2. يفتح الموقع الرئيسي عبر: https://saifshoping.com
3. لوحة الأدمن تظهر فقط عبر: https://saifshoping.com/admin-saif-shop
4. دخول الأدمن الافتراضي: admin / saif1234 — غيّره فوراً من تبويب الإعدادات.

ملاحظات مهمة:
- رقم الواتساب ورابط الانستا وكلمة مرور الأدمن تُغيَّر من لوحة الأدمن > الإعدادات.
- الأزرار الخضراء تحت كل منتج تفتح واتساب الأدمن برسالة تتضمن تفاصيل المنتج تلقائياً.
- زر "إرسال الطلب عبر واتساب" داخل العربة يرسل كل المنتجات + المجموع.
- البيانات (منتجات/فئات/إعدادات) تُحفظ في متصفح الجهاز المستخدم للإدارة.
  عند تغيير الجهاز استخدم "تصدير نسخة احتياطية" و"استيراد" لنقلها.
- لا يحتاج الموقع لقاعدة بيانات — يعمل على أي استضافة ثابتة (حتى GitHub Pages).
